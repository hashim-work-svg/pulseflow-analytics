## 🎯 What it does
PulseFlow is a human-crafted SaaS revenue and cohort intelligence dashboard inspired by top-tier modern product design studios (Paperpillar, Linear, Vercel).

Instead of generic neon layouts or bloated chart libraries, PulseFlow is engineered with meticulous attention to typography, tabular figure alignment, subtle slate palettes, interactive SVG curves, and realistic subscription lifecycle states.

### Key Highlights:
1. **Human-Crafted Micro-Interactions**: Custom keyboard shortcut (`⌘K` search), time-window toggles (`7D`, `30D`, `90D`, `12M`), and cohort tier filters.
2. **Zero-Dependency Vector Data Visuals**: Native SVG area curves and progress distributions delivering 60 FPS silky smooth rendering without bundle bloat.
3. **Realistic Financial Metrics**: Net MRR, Net Revenue Retention (NRR 124.8%), LTV/CAC ratios (5.2x), and negative churn tracking.
4. **Sub-100ms Load Time**: Zero NPM packages, pure vanilla HTML5/CSS/JavaScript.

---

## 🛠️ Architecture & Tech Stack
- **Design Tokens**: Slate matte canvas (`#090B11`), Indigo accent (`#6366F1`), Emerald status badges
- **Typography**: Native system font stack with `tabular-nums`
- **Vector Graphics**: Native SVG paths with cubic bezier gradient fills

## 🚀 Getting Started
Open `index.html` directly in Chrome/Safari or run:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080`.
